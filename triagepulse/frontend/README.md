# TriagePulse — Frontend Web Application

> **Hospital Command Center & Bedside Nurse Triage Dashboard**  
> *React 18 + Vite + TypeScript + Tailwind CSS + Recharts + Lucide Icons*

---

## 🚀 Quick Start

### 1. Installation
```bash
npm install
```

### 2. Development Server
```bash
npm run dev
```
The dashboard will launch at: [http://localhost:5173](http://localhost:5173)

### 3. Production Build
```bash
npm run build
```
Builds the optimized production assets into `dist/`, which is also automatically served by the FastAPI backend at `http://localhost:8000`.
